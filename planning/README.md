# TradeEdge Planning Documents

This folder contains planning and implementation documentation for major TradeEdge features.

## Autopilot Documents

- `AUTOPILOT_SPEC_v1.0.md` — approved paper-mode functional specification and implementation architecture baseline.
- `AUTOPILOT_RELEASE_PLAN_v1.0.md` — sprint-by-sprint delivery plan for paper-mode Autopilot.
- `AUTOPILOT_TECHNICAL_DESIGN.md` — evolving technical design notes, API contracts, Redis schema, and implementation decisions.
- `AUTOPILOT_CHANGELOG.md` — material changes after the v1.0 planning baseline.

## Rule

The specification is the contract. The release plan is the build sequence. The technical design records implementation details. The changelog records intentional deviations or revisions after v1.0.
