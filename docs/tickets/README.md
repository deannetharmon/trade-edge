# Trade Edge tickets

This folder holds every ticket, past and present. It's an archive, not an index — it stopped being kept current a long time ago (it used to list about 24 of the 127 files here, in an order that no longer matches how the project actually progressed, and it linked at least one file that no longer exists).

**For current, accurate status, use these two files instead:**

- `docs/ROADMAP.md` — the maintained source of truth for active and upcoming work.
- `docs/TICKET-STATUS.md` — a full reconciliation of every file in this folder (done / outstanding / superseded / reference), kept current as tickets change status.

## Ticket format

Each ticket should include: Problem, User value, Scope, Non-goals, Acceptance criteria, Implementation notes, Validation steps, Rollout notes.
