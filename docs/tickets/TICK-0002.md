# TICK-0002: the broker's tick size is the source of truth

Trigger: NVDL CSP (28P, 2026-11-20) dry run rejected: "Price must be in increments of $0.05 for this order." Sent entry $1.39, target $0.69, stop trigger $2.78, stop limit $3.10. The chain published "$0.01 below $3, then $0.05".

## Rules (Ian, Alan, Quinn)
- Effective tick = max(broker-stated tick, chain table tick at that price), learned per OPTION ROOT (NVDL is not NVDA), kept in page memory.
- Entry credit snaps DOWN to the tick (never below one tick). Exits derive from the snapped entry.
- Exits keep ORDER-TICK-0001 rounding (nearest; target below entry; stop limit rounded up and at or above trigger). Not "round up" for the stop trigger: that broke the approved fixture.
- A rejected DRY RUN is retried at most once at the tick the broker names. No retry when the message names no tick, names a tick already in force, or is unreadable.
- A rejected LIVE submit is never resent automatically. The tick is remembered and the trader is told to review and place again.
- +/- entry buttons step by tick and always land on a valid price. An entry exactly one tick wide has no room for a target and is a visible error.
