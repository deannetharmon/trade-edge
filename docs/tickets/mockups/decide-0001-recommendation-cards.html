Notes for Dane

  • Order: urgent (confirming stop, stop, broken) → needs action (profit, time, roll, assignment, no recommendation) → holding table.
  • The action label is the only saturated color on the card. Red for stop and broken, teal for profit and time closes, blue for roll and assignment, amber for blocked, grey for hold.
  • Confidence uses three bars plus the word, never color alone. BLOCKED shows no confidence.
  • The UI branches on reasonCode: STOP_PENDING_CONFIRMATION gets the red banner with a countdown; DATA_UNAVAILABLE gets the amber banner listing the missing fields.
  • Reasons: top 3 only. Supporting signals are labeled "(supporting)".
  • The AI explanation and any dissent stay collapsed. The disclaimer appears once per page.
  • Buttons open the existing order review. No order is sent from the card.
