# Trade Edge Decision Records

This folder contains architecture and product decision records for Trade Edge.

Use decision records when a choice affects architecture, product behavior, trading workflow, or future implementation direction.

## Decision record format

Each decision should include:

- Status
- Context
- Decision
- Consequences
- Follow-ups
